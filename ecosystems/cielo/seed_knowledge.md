# Base inicial — Cielo Instituição de Pagamento

Esta síntese inicial cobre oito páginas oficiais indicadas pelo usuário. Não substitui referências técnicas completas.

## Cielo Smart
Fonte: https://docs.cielo.com.br/cielo-smart/docs/conheca-a-cielo-smart
A Cielo Smart é descrita como plataforma aberta para aplicativos Android voltados ao varejo, integrando frente de caixa, gestão de negócios e meios de pagamento. A página menciona aplicativos públicos e privados e integração com sistemas de automação.

## API Pix
Fonte: https://docs.cielo.com.br/pix-can-cbk/docs/conheca-api-pix
A página descreve a API Pix como solução da Cielo na condição de prestadora de serviços de pagamento, provedora de conta transacional e participante direto do Pix. A interface automatiza a interação com participantes do Pix; as APIs de recebimento abrangem geração de QR Codes, gestão de pagamentos e conciliação. A elegibilidade indicada é para clientes PJ com Pix habilitado.

## API Única de Cancelamento
Fonte: https://docs.cielo.com.br/pix-can-cbk/docs/conheca-a-api-unica-de-cancelamento
Centraliza cancelamentos de vendas de POS, LIO, TEF e E-commerce, permite consultar status e gerar cartas de cancelamento efetivadas. Credenciais são concedidas por raiz de CNPJ. A versão descrita não suporta cancelamento de Pix, Voucher e pré-autorização.

## Tap on Phone iOS
Fonte: https://docs.cielo.com.br/conecta/docs/requisitos-ios
A página lista requisitos do SDK para iOS, incluindo iOS 18.5+, internet, 50 MB livres, NFC e iPhone XS ou mais recente, além de exigências da Apple. Revalidar a documentação atual antes de desenvolver.

## Cielo Conecta
Fonte: https://docs.cielo.com.br/conecta/docs/conheca-o-cielo-conecta
Permite integrar parceiros e subadquirentes à Cielo para transações com cartões presentes (chip/tarja) e não presentes (digitadas). A página cita tokenização, consulta de transação, gestão de Pin Pad, lojas, terminais e informações para conciliação.

## API de Chargeback
Fonte: https://docs.cielo.com.br/pix-can-cbk/docs/conheca-chargeback
Permite consultar contestações pendentes e tratadas, aceitar ou recusar, visualizar ciclo de vida, baixar documentos e configurar webhooks de notificações.

## Extrato Eletrônico
Fonte: https://docs.cielo.com.br/extrato-webview/docs/conheca-o-extrato-eletronico
Disponibiliza dados estruturados de vendas, pagamentos, negociações e saldo em aberto para automatizar conciliação financeira e reduzir intervenção manual.

## Carta de Circularização
Fonte: https://docs.cielo.com.br/extrato-webview/docs/conheca-a-carta-de-circularizacao
Produto gratuito mediante solicitação para consulta mensal de recebíveis futuros, negociações e valores em aberto. A página descreve três relatórios: Carta de Circularização, Carta Sintética e Carta Analítica.

## Limite de inferência
Não inferir endpoints, schemas, códigos de erro, SLA, regras contratuais ou requisitos de segurança que não estejam explicitamente nas fontes recuperadas.

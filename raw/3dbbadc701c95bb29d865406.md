# Consultando credenciais cadastradas 

Após a aprovação da solicitação, o ponto focal do estabelecimento receberá um e-mail confirmando a criação das credenciais. Em seguida, faça o cadastro no Portal de Desenvolvedores Cielo seguindo as instruções abaixo.

1. [Acesse o Portal de Desenvolvedores Cielo](https://desenvolvedores.cielo.com.br/api-portal/).

<Callout icon="👍" theme="okay">
  O cadastro deve ser realizado com o mesmo e-mail do ponto focal do Estabelecimento enviado na solicitação de credenciais. 
</Callout>

<Image align="center" width="700px" src="https://files.readme.io/053b439ee06fb4eed80dc45a2576dfc867c4374bff7751833cf559b03370d5e0-cadastrese.png" />

2. Preencha o e-mail de quem fará o gerenciamento das credenciais para acessar a API de cancelamento e demais dados do Estabelecimento.

<Image align="center" width="500px" src="https://files.readme.io/74c1580ab3207a64443c1e0a18f3af92949d4375332cb93c49a91d5fdc385754-campos.png" />

3. Após preencher todos os campos, clique em **Criar nova conta**.
4. Após concluir o cadastro, você receberá um e-mail de confirmação. Acesse esse e-mail e clique no link enviado para validar o primeiro acesso.
5. Altere a senha inicial e salve as alterações.
6. Para ter mais segurança no acesso às credenciais, clique no botão **Configurar Aplicativo** e instale em seu dispositivo móvel ou desktop aplicativo de duplo fator de autenticação que preferir.

* Google Authenticator (Android/iPhone/BlackBerry)

* Authy (Android/iPhone)

* Authenticator (Windows Phone)

* FreeOTP (Android)

* GAuth Authenticator (Firefox OS, desktop, outros)

<Image align="center" src="https://files.readme.io/91d025524f83623252a1492d5c110ff9d24b7984035a00ff89a82267981255c9-confiapp.png" />

O aplicativo de autenticação de dois fatores será usado durante esta configuração e para gerar códigos durante a autenticação regular. Se o aplicativo for compatível, realize a leitura do código QR Code para obter o código de configuração. Caso contrário, você poderá inserir manualmente o código de texto. [Clique aqui para instalar o app](https://www.microsoft.com/pt-br/security/mobile-authenticator-app).

7. Forneça a senha atual e valide código fornecido no aplicativo de duplo fator de autenticação. Após concluída a autenticação, a mensagem “Configuração do TFA concluída” será exibida e poderá ter acesso a sua conta conforme dados enviados por e-mail.

## Acessando as credenciais cadastradas

1. No canto superior direito, clique em **Perfil > Client-Ids Cadastrados**.

<Image align="center" src="https://files.readme.io/6340a0f41c8468b91d076c13e9a474a609a81d8f3e0186033922eda71de6c3e5-clientid.png" />

2. Você será redirecionado para uma tela que exibirá suas credenciais.

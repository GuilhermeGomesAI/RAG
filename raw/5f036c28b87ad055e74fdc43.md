# Perguntas frequentes

Aqui, você encontra as respostas para as perguntas mais frequentes sobre a API Pix para facilitar sua jornada com a gente!

# Modalidades de recebimento Pix

<Accordion title="Se uma modalidade não for definida, qual será considerada?" icon="fa-info-circle">
  Nesse caso, será considerada a primeira modalidade habilitada para o Estabelecimento Comercial.
</Accordion>

<Accordion title="Posso realizar a alteração de modalidade somente para um Estabelecimento Comercial?" icon="fa-info-circle">
  Não. A Alteração da modalidade será aplicada para todos os ECs vinculados ao CNPJ.
</Accordion>

<Accordion title="A alteração de modalidade é realizada de forma imediata?" icon="fa-info-circle">
  Não. A troca de modalidade não ocorre de forma instantânea. Quando você solicita a mudança, é criado um agendamento, e a alteração é efetivada à 0h00 do dia seguinte. Esse processo garante uma conciliação mais organizada e precisa para o cliente.
</Accordion>

<Accordion title="Ao cancelar a modalidade que estava usando, ocorrerá uma migração automática para outra modalidade contratada?" icon="fa-info-circle">
  Não. A migração não ocorre de forma automática. Caso você cancele a modalidade em uso, você deve acessar o site e selecionar manualmente qual das demais modalidades contratadas deseja ativar.
</Accordion>

<Accordion title="Após a troca da modalidade, consigo consultar as vendas realizadas na modalidade antiga?" icon="fa-info-circle">
  As vendas realizadas nos últimos 90 dias e transacionadas na modalidade Pix na Cielo ficarão disponíveis para consulta no site, disponíveis na aba **Pix**.
</Accordion>

<Accordion title="*Se eu tiver saldo em conta no Pix na Cielo e trocar a modalidade para o Pix nos Bancos, o que acontece com o meu saldo?*" icon="fa-info-circle">
  O saldo permanece disponível na sua conta. Se você utiliza transferência automática ou transferência programada e houver algum problema com o domicílio bancário, basta corrigir os dados para que o valor seja devidamente liquidado. Já no caso de livre movimentação, neste momento, é necessário retornar para a modalidade Pix Cielo para realizar o resgate do saldo disponível em conta.
</Accordion>

# Pix Cobrança

<Accordion title="Quais campos são obrigatórios para criar uma cobrança?" icon="fa-info-circle">
 Para criar uma cobrança, os seguintes campos são obrigatórios: 

- valor.original: Representa o valor total da cobrança, expresso como string numérica com duas casas decimais (por exemplo, "150.00").  É o valor que será efetivamente cobrado do pagador.  
- calendario.expiracao: Define o tempo de expiração da cobrança, em segundos, a partir do momento de sua criação. Após esse período, a cobrança deixa de ser válida para pagamento, o que ajuda a evitar pagamentos fora do contexto esperado. Caso não informado, é utilizado o valor default. 
- chave: Corresponde à chave Pix do usuário recebedor (CPF, CNPJ, e-mail, telefone ou chave aleatória). Na Cielo, sempre será a chave aleatória.  

Além disso, campos opcionais, como infoAdicionais, são recomendados para facilitar a conciliação e a identificação do pagamento.
</Accordion>

<Accordion title="O Pix Cobrança permite pagamentos parciais? " icon="fa-info-circle">
Não. O Pix Cob não suporta pagamento parcial. O valor pago deve ser exatamente igual ao valor definido na cobrança. Caso o pagador tente realizar um pagamento com valor diferente, a transação será rejeitada. 
</Accordion>

<Accordion title="Como é feita a confirmação do pagamento de uma cobrança? " icon="fa-info-circle">
A confirmação pode ocorrer de duas formas: 

- Consulta ativa (Polling): verificação periódica da cobrança, observando o campo Pix vinculado. 
- Webhook: notificação assíncrona enviada pelo PSP do usuário recebedor quando o pagamento é liquidado. 

Após a liquidação, a cobrança passa a conter um ou mais objetos Pix, com informações como: 

- Valor: Valor do Pix. 
- Horário: Horário em que o Pix foi processado no PSP. 
- EndToEndId: É Id fim a fim da transação Pix, conforme padrão estabelecido pelo Banco Central. 
</Accordion>

<Accordion title="O Pix Cobrança suporta identificação do pagador? " icon="fa-info-circle">
Sim. É possível informar dados do pagador de forma opcional, como: devedor.nome, devedor.cpf ou devedor.cnpj. Essas informações auxiliam na conciliação, mas não são obrigatórias para a liquidação do pagamento. 

Mesmo com os dados do devedor informados, a cobrança não fica restrita a esse usuário, permitindo que qualquer pessoa realize o pagamento.
</Accordion>

<Accordion title="Quais são os principais status de uma cobrança Pix Cob? " icon="fa-info-circle">
Uma cobrança Pix Cob pode apresentar os seguintes status:

- Ativa/Criada: cobrança válida e disponível para pagamento.
- Concluída (Liquidada): pagamento realizado com sucesso.
- Expirada: prazo de pagamento encerrado.
- Removida/Cancelada: cobrança invalidada manualmente (quando permitido).

O status pode ser consultado por meio do endpoint de consulta de cobrança.
</Accordion>

# Pix Automático

<Accordion title="Eu preciso solicitar habilitação do Pix Automático?" icon="fa-info-circle">
  Não. A funcionalidade já está disponível para clientes que possuem o Pix habilitado na Cielo. Caso você ainda não tenha o produto habilitado, entre em contato com o seu representante Cielo. Caso você já tenha o produto habilitado, você deverá fazer a integração com a API Pix ou API E-commerce e, em seguida, ofertar o Pix Automático para os seus clientes.
</Accordion>

<Accordion title="Quem pode se enquadrar como usuário recebedor do Pix Automático?" icon="fa-info-circle">
  Pessoas jurídicas com número de inscrição no CNPJ ativo podem se enquadrar como usuários recebedores do Pix Automático. Os PSPs recebedores devem adotar controles para garantir que a funcionalidade não seja disponibilizada a usuários recebedores com indícios de fraude ou má conduta.
</Accordion>

<Accordion title="Uma recorrência precisa ter vigência ou quantidade de pagamentos pré-definidos?" icon="fa-info-circle">
  Não necessariamente. A vigência da recorrência é definida conforme o acordo entre o recebedor e o pagador. A autorização pode ser concedida por prazo indeterminado ou, alternativamente, conter parâmetros pré-definidos, como o número máximo de cobranças ou uma data final de vigência.
</Accordion>

<Accordion title="O cancelamento da autorização cancela automaticamente a recorrência?" icon="fa-info-circle">
  Sim. O cancelamento de uma autorização resulta automaticamente no cancelamento da recorrência, e o inverso também é válido. O cancelamento ocorre de forma imediata. No entanto, agendamentos previamente existentes com liquidação prevista para o mesmo dia serão mantidos. Após o cancelamento da recorrência, o usuário recebedor não poderá mais enviar instruções de pagamento para débitos futuros.
</Accordion>

<Accordion title="O que acontece se, no dia do pagamento, o portador não tiver limite ou saldo?" icon="fa-info-circle">
  Caso o portador não possua limite ou saldo no dia do pagamento, será possível solicitar um ajuste de limite, que deverá ser atendido em até oito horas, permitindo uma nova tentativa de pagamento no mesmo dia. Na ausência de saldo, o portador poderá realizar um depósito na conta para viabilizar a conclusão da operação.
</Accordion>

<Accordion title="O que acontece se o portador não tiver saldo, inclusive nas retentativas?" icon="fa-info-circle">
  Após o esgotamento de todas as tentativas de cobrança, o cliente (EC) será notificado por meio de Webhook e deverá adotar uma forma alternativa de cobrança junto ao cliente final. A autorização do usuário pagador permanecerá vigente, exceto em caso de cancelamento explícito da autorização.
</Accordion>

<Accordion title="O portador será notificado a cada cobrança?" icon="fa-info-circle">
  Sim. O Pix Automático prevê o envio de comunicações sobre agendamentos e cobranças ao portador, realizadas diretamente pelo banco do próprio portador.
</Accordion>

<Accordion title="Como funciona a devolução no Pix Automático?" icon="fa-info-circle">
  A devolução no Pix Automático segue as mesmas regras e parâmetros aplicáveis à devolução do Pix tradicional, não havendo qualquer diferença em relação ao processo padrão.
</Accordion>

<Accordion title="As taxas do Pix Automático são as mesmas que o Pix convencional?" icon="fa-info-circle">
  Sim. As taxas seguirão as mesmas taxas que o cliente já tem cadastrado para o Pix Convencional.
</Accordion>

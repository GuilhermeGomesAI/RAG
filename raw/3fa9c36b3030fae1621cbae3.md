# RecPayload: Payload da recorrência

Reúne endpoints (locations) utilizados pelo software do PSP pagador para recuperar o payload JSON que representa uma recorrência.

<Callout icon="📘" theme="info">
  Os endpoints listados apresentam requisitos de autenticação e autorização diferenciados em relação aos outros endpoints listados na presente API. São endpoints abertos para que qualquer cliente da internet possa se conectar. Cada location é uma url de capacidade, funcionalidade implementada via o fragmento {recUrlAccessToken}.
</Callout>

* [Recuperar o payload JSON que representa a configuração da recorrência](https://docs.cielo.com.br/pix-can-cbk/reference/recuperar-payload-json).

# Glossário

Este glossário reúne os principais termos utilizados no ecossistema de desenvolvimento da API de Chargeback.  Ele foi criado para facilitar a compreensão de conceitos técnicos e operacionais, promovendo uma integração mais eficiente com nossas soluções. Consulte-o sempre que tiver dúvidas sobre nomenclaturas ou funcionalidades.

| Termo                                   | Descrição                                                                                                                                          |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| API de Chargeback                       | Interface que permite integrar sistemas à Cielo para gerenciar contestações, incluindo consulta, aceite, recusa e acompanhamento do ciclo de vida. |
| Chargeback (Contestação)                | Processo em que o cliente contesta uma transação junto ao banco emissor, solicitando a reversão do valor.                                          |
| Aceite de Contestação                   | Ação em que o estabelecimento concorda com a contestação, permitindo o estorno do valor ao cliente.                                                |
| Recusa de Contestação                   | Ação em que o estabelecimento contesta a reclamação, enviando evidências para defesa da transação.                                                 |
| Ciclo de Vida da Contestação            | Etapas que uma contestação percorre desde a abertura até a sua finalização.                                                                        |
| Webhook                                 | Mecanismo de notificação automática que envia atualizações em tempo real sobre eventos da API.                                                     |
| Documento do Emissor                    | Arquivo disponibilizado pelo banco emissor com informações da contestação.                                                                         |
| Documento de Defesa                     | Evidências enviadas pelo estabelecimento para justificar a legitimidade da transação.                                                              |
| Sandbox                                 | Ambiente de testes isolado para simular integrações sem impactar o ambiente produtivo.                                                             |
| Produção                                | Ambiente real onde as operações e contestações são processadas.                                                                                    |
| Credenciais (Client ID / Client Secret) | Dados utilizados para autenticar a aplicação e obter acesso à API.                                                                                 |
| Token de Acesso (Access Token)          | Credencial temporária usada para autorizar requisições à API.                                                                                      |
| MTLS (Mutual TLS)                       | Método de autenticação com certificados digitais para comunicação segura entre cliente e API.                                                      |
| Certificado Digital                     | Arquivos utilizados na autenticação MTLS (.csr, .key, .crt).                                                                                       |
| Endpoint                                | URL que representa um serviço específico da API.                                                                                                   |
| IdChargeback                            | Identificador único de uma contestação.                                                                                                            |
| IdCase                                  | Identificador do caso relacionado à contestação.                                                                                                   |
| Estabelecimento Comercial (EC)          | Número que identifica o estabelecimento na Cielo.                                                                                                  |

# Adicionando o certificado MTLS no Postman

Nesse tópico serão fornecidas informações sobre como anexar o certificado assinado pela Cielo na API Única de Cancelamento.

Na ferramenta do Postman, vá para o ícone de **Ferramentas > Configurações > Certificados >**. Então, anexe o arquivo .crt assinado pela Cielo e o .key.

<Callout icon="📘" theme="info">
  Este passo deve ser feito tanto para o ambiente de produção quanto para o de homologação, mas você pode usar o mesmo certificado, apenas alterando o campo **Host**.
</Callout>

Acesso aos endpoints da Cielo:

| Ambiente            | URL Base                                                                  |
| ------------------- | ------------------------------------------------------------------------- |
| Homologação/Sandbox | `https://apihml-internet.cielo.com.br/refunds-api/v1`                     |
| Produção/External   | `https://api-internet.cielo.com.br/cielo-refunds-exp-external/refunds/v1` |
